# 湖影公园 · 游船排队与救生衣核验平台

售票后进入候船队列，工作人员按船型和人数组批，登船前逐人确认救生衣尺码并锁定船只；
出航后记录预计回港时间，完成回港检查和救生衣归还才结束订单。天气停航期间不能创建
新的出航批次，已组批未出航的批次自动解散并退回候船队列。

## 一条命令启动（带样例数据）

```bash
python3 run.py --fresh
# 默认 http://127.0.0.1:8000 ，可用 --port 改端口；不加 --fresh 则复用 data/lake.db
```

仅依赖 Python 3.11 标准库（http.server + sqlite3），无需安装任何第三方包。

## 六个工作台

| 页面 | 地址 | 说明 |
| --- | --- | --- |
| 候船叫号屏 | `/screen` | 突出号码、船型与预计等待时间；停航横幅呼吸提示 |
| 组批工作台 | `/workbench` | 售票、叫号、过号重排、按船组批锁定、临时换船、天气控制 |
| 登船核验 | `/boarding` | 逐人 S/M/L/XL 救生衣确认；G1/G2 双闸口扫描；出航 |
| 湖面计时 | `/lake` | 低信息密度卡片；超时船只仅边框脉冲（尊重减弱动态效果设置） |
| 回港检查 | `/dock` | 船体刮碰登记、照片本地存盘、救生衣缺失、归还确认 |
| 押金复核 | `/deposit` | 扣款金额由回港检查带出，幂等结算 + 模拟支付流水 |

页面通过 SSE（`/api/events`）在任何状态变化后自动刷新，并带 15 秒轮询兜底。

## 关键业务规则

- **并发放行**：两处闸口同时扫描同一候船号，条件 UPDATE（READY→BOARDING）保证只
  放行一次，另一侧收到“已在另一闸口放行”的幂等回放，扫描次数照常累加。
- **过号重排**：叫号 3 分钟未到（调度器自动标记）转 MISSED；显式重排后给新的队尾
  序号 `priority_seq`，可继续正常组批登船。
- **容量约束**：组批合计人数不得超过船型上限；临时换船可跨船型但新船上限仍为硬约束；
  同船并发组批由船只 DOCKED→LOCKED 的 CAS 拦截。
- **儿童尺码**：S 码为儿童码，按船型维护实物库存（跨批次全局占用，归还后释放），
  库存不足组批/逐人确认都会被拒。
- **停航中断**：停航时禁止组批与出航；已组批批次自动 SUSPENDED、票据回 WAITING、
  船只释放；湖面船只产生催促回港事件；恢复后游客可重新走完流程。
- **超时未归**：进程内调度器每 10 秒扫描，回港前 5 分钟提醒、超时升级 OVERDUE。
- **押金幂等**：结算必须关联已完成的回港检查；`settlements.ticket_id` 唯一 + 支付
  渠道幂等键 `ded:<ticket_id>`，重复提交回放首次结果，绝不重复扣款。
- **船体照片**：上传后写入本地 `photos/`，数据库只存相对路径。

## 演示数据与模拟适配器

- 游客资料、押金/扣款支付记录均为演示数据（`app/seed.py`、`app/adapters.py`）。
- `WeatherAdapter` 可在工作台一键切换 NORMAL / WARNING / SUSPEND。
- `PaymentAdapter` 按幂等键返回同一笔渠道流水（构造时传入 fail_keys 可模拟支付失败）。

## 测试

无需 pytest，标准库即可：

```bash
python3 -m unittest discover -s tests -p 'test_*.py'
```

覆盖：并发双闸口只放行一次、过号恢复、容量/换船/儿童尺码约束、停航中断与恢复、
押金结算幂等（含刮碰扣款、救生衣缺失均摊）、超时升级、照片落盘，共 26 个用例。

## 代码结构

```
app/
  db.py         SQLite schema（进程内写锁 + IMMEDIATE 事务）
  adapters.py   天气 / 支付模拟适配器
  service.py    全部业务规则与状态机
  scheduler.py  进程内定时任务（过号、回港提醒、超时）
  events.py     SSE 发布订阅
  server.py     HTTP 路由 / JSON API / SSE
  seed.py       样例数据
static/         六个页面 + 公共样式/脚本
photos/         船体照片本地目录
tests/          unittest 测试
run.py          启动入口
```
