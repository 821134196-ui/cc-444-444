# 湖湾公园游船排队与救生衣核验平台

售票入队 → 叫号组批 → 救生衣逐人核验 → 闸口放行 → 出航计时 → 回港检查 → 押金复核的
全流程演示应用。**仅依赖 Python 3.11 标准库**（`http.server` + `sqlite3` + 线程），
游客资料与支付记录使用演示数据，天气与付款由模拟适配器生成。

## 一条命令启动

```bash
./run.sh          # 默认 http://127.0.0.1:8000
./run.sh 9000     # 指定端口
```

脚本会自动建库、写入样例数据（候船队列、过号号码、一个正在湖面的航次）、
启动 Web 服务与进程内后台任务。首次启动后直接打开 **http://127.0.0.1:8000/board** 即可看到候船大屏。

## 六个工作台

| 页面 | 地址 | 内容 |
|---|---|---|
| 候船叫号屏 | `/board` | 大字突出候船号、船型、人数与预计等待时间；叫号横幅；5 秒自动刷新 |
| 组批工作台 | `/workbench` | 叫号、过号重排、按船型组批、容量进度、锁船、解散（停航中断） |
| 登船核验 | `/boarding` | 逐人确认救生衣尺码、库存余量、两处闸口扫码、临时换船、出航 |
| 湖面计时 | `/lake` | 低信息密度卡片；超时船只仅**边框脉冲**提示，不做大面积闪烁 |
| 回港检查 | `/return` | 船体正常/刮碰/严重损伤、救生衣缺失勾选、上传或模拟船体照片 |
| 押金复核 | `/deposit` | 按刮碰分摊、缺衣、超时计费，余额退还；大按钮防误触，幂等结算 |

首页 `/` 提供演示售票表单与天气控制（适航 / 大风 / **停航**）。

## 关键业务规则与异常处理

- **过号重排**：叫号 120 秒未到自动过号；重排保留原号码但回到**队尾**（`requeued_at` 重排），累计重排次数。
- **儿童尺码不足**：救生衣按尺码记账占用，库存为 0 时拒绝分配并提示调拨/改签。
- **临时换船**：仅允许同船型船只，换船前后人数上限不变，旧船立即释放。
- **超载**：单团超单船上限售票即拒；组批加入号码时实时校验载客上限。
- **超时未归**：后台任务每 10 秒扫描，超过预计回港时间即告警并广播，**每批次只告警一次**。
- **船体刮碰**：回港检查登记轻微刮碰（分摊扣款）或严重损伤（船送修）。
- **天气突变 / 停航**：`storm` 状态下禁止创建新批次、禁止锁船、禁止出航，并向大屏推送停航广播；
  在组批/登船中的批次可一键解散，号码回到队尾；复航后恢复正常。
- **双闸口并发放行**：`gate_scans.ticket_id` 唯一约束兜底，两处闸口同时扫描同一候船号**只能放行一次**。
- **押金幂等**：押金扣除必须先有关联的回港检查；扣款/退款以 `票+检查单` 构成唯一幂等键，
  重复提交（含并发）**绝不重复扣款**，直接返回既有结算结果。

## 数据与文件

- SQLite：`app/data/boat.db`（自动创建；WAL 模式），表结构见 `app/schema.sql`。
- 船体照片：`app/data/photos/`，真实上传文件或无文件时生成 SVG 占位图。
- 后台任务（`app/tasks.py`）：超时扫描、叫号过期、模拟天气评估与停航广播，全部在进程内线程运行。

## 测试

```bash
python3 -m unittest discover -s tests -v
```

覆盖 19 个用例，重点包含：

- `test_two_gates_concurrent_only_one_wins`：20 个并发闸口请求仅放行一次；
- `test_missed_then_restore_to_tail`：过号重排到队尾并可再次叫号；
- `test_batch_overload_rejected` / `test_switch_boat_same_type_keeps_limit`：容量与换船约束；
- `test_storm_blocks_new_batch_and_departure` / `test_storm_interrupts_boarding_batch`：停航中断；
- `test_settle_fees_and_idempotent_repeat` / `test_concurrent_settle_charges_once`：
  押金结算重复/并发提交只扣一次，且无回港检查不得结算。

## 代码结构

```
app/
  schema.sql    表结构与索引
  db.py         连接、建库、演示数据
  adapters.py   天气 / 支付 模拟适配器
  services.py   业务服务层（队列、组批、核验、闸口、航次、检查、押金幂等）
  tasks.py      进程内后台任务
  web.py        HTTP 路由与六个页面（湖水青 #1f8a96 / 救生衣橙 #f26a13 / 深灰 #2b2f33）
run.py / run.sh 启动入口
tests/          业务与并发测试
```
